# Narrative-to-Scene Generation (EXAG 2025)

## TL;DR
This repository contains the full **Narrative-to-Scene Generation** pipeline introduced in our **EXAG 2025** paper.  
Given a short story generated by GPT-4, the system automatically:
1. Extracts objects and spatial relations from the narrative,  
2. Assigns semantic affordances (terrain, environment, interactive, item, character),  
3. Generates layered tile based scenes through Cellular Automata and affordance reasoning, and  
4. Builds visual and knowledge graph representations aligned with the story timeline.

All visual assets and semantic labels are derived from the **GameTileNet Dataset** (AIIDE 2025).

---

## Highlights
- **LLM driven narrative parsing** → story → time frames → scene relations  
- **Affordance classification** using GPT-4 for semantic grounding  
- **Layered scene generation** with base terrain, patches, and objects  
- **Scene level knowledge graphs** integrated with temporal links  
- **Automatic object to image matching** via SentenceTransformer embeddings  
- **Quantitative evaluation** of affordance alignment, diversity, and spatial predicate satisfaction  
- **Reproducible examples:** 10 stories (`StoryFiles/0` to `StoryFiles/9`) with processed outputs

## Quick start
### 1) Generate a new story
```bash
python Story_1_NarrativePrompt_langchain_v4.py
```
Saves `StoryFiles/<id>_adventure_scene_output_FIXED.json`.

### 2) Classify object affordances
```bash
python Story_2_TerrianAnalysis.py
```

### 3) Parse scenes and build knowledge graphs
```bash
python Story_11_ConstructSceneKG_combined_timeline_patch.py
```

### 4) Match objects to GameTileNet assets
```bash
python Generation_3_parse_story_mapping_with_eval.py
```

### 5) Render layered visual scenes
```bash
python Scene_4_replace_objects_v2.py
```

### 6) Evaluate matching quality
```bash
python Generation_4_story_eval_metrics.py
```

Result images and metrics appear under `StoryFiles/`.

## Concepts
**Pipeline overview**

| Stage | Description |
| --- | --- |
| **Narrative generation** | GPT 4 produces story text, time frames, and `[Object][Relation][Object]` triples. |
| **Affordance reasoning** | Each object receives a terrain linked affordance category (terrain, environment, interactive, item, character). |
| **Scene composition** | Cellular Automata expand base and patch terrains, then object placement forms multi layer grids. |
| **Knowledge graphs** | Scene graphs merge into a story level graph with temporal `precedes` edges. |
| **Object to asset matching** | SentenceTransformer MiniLM retrieves semantically aligned GameTileNet images. |
| **Evaluation** | Affordance match rate, cosine similarity, diversity, and spatial predicate satisfaction. |
